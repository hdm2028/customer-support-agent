# 数据说明

这个目录是中文电商智能售后客服 Agent 的学习数据。

## knowledge

`knowledge` 文件夹保存售后政策知识库，后面会用于 RAG 检索。

当前包含：

- `退换货政策.md`
- `物流配送政策.md`
- `保修政策.md`
- `会员权益政策.md`
- `售后FAQ.md`
- `订单取消与修改政策.md`
- `支付与发票政策.md`
- `库存与补货政策.md`

## orders.json

`orders.json` 是模拟订单数据库，后面会用于订单查询工具。

订单数据用于练习：

- 根据订单号查询商品和订单状态。
- 根据签收时间判断是否可能在退货期或保修期内。
- 结合售后政策生成客服回复。

## intents

`intents/customer_support_intents.json` 保存中文电商售后客服意图分类。

它主要用于理解 Router 应该识别哪些业务问题，例如：

- 订单状态
- 退货退款
- 保修维修
- 物流异常
- 支付异常
- 发票问题
- 库存补货
- 投诉升级

## eval

`eval/customer_support_eval.jsonl` 是后续评估集。

它可以用于测试：

- 路由是否正确。
- 工具是否调用正确。
- 高风险请求是否被拦截。
- RAG 是否能召回正确政策。

## dataset_sources.md

`dataset_sources.md` 记录数据来源、参考项目和改造说明，方便后续写简历和项目文档。

## 注意

这些数据是教学模拟数据，不是真实用户数据。智能客服 Agent 不能自动退款、赔付、取消订单或修改真实数据库。
