# 订单取消与修改政策

## 未支付订单取消

未支付订单通常可以由用户自行取消。由于用户尚未完成付款，取消未支付订单不会产生退款流程。

智能客服 Agent 可以引导用户进入订单详情页取消，但不能代替用户完成真实取消操作。

## 待发货订单取消

待发货订单是否可以取消，取决于仓库是否已经开始拣货、打包或出库。

如果订单仍未进入仓库出库流程，可以创建取消订单工单，由人工客服或仓库系统确认。

如果订单已经出库或交给快递公司，通常不能直接取消，需要等待物流拦截结果或签收后申请售后。

## 修改收货地址

待发货订单可能支持修改收货地址，但必须在仓库出库前处理。

智能客服 Agent 不应直接承诺已经修改地址，只能创建地址修改工单，并提示用户最终结果以人工客服和仓库确认结果为准。

## 已发货订单修改

已发货订单通常不能直接修改地址。如果快递公司支持改派，可以由人工客服协助提交改派申请。

改派不保证一定成功，且可能影响配送时效。
