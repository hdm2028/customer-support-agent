# 业务语义修正与正式持久化接入

本轮先修复关键词审计中确认的误判，再把已有隔离图运行器接入正式鉴权接口。未运行五层评测，未修改评测集、评分规则或 RAG 默认实验开关。

## 业务误判与上下文

| 已确认问题 | 本轮修改与检查 |
|---|---|
| “没有质量问题，只是不想要”被识别为质量退款，影响定制商品资格 | 退款原因、质量判断共用 `asserted_mentions`，显式否定不计入肯定信号；该句归入无理由退款，定制商品不获得质量例外 |
| “我不投诉，也不要求直接退款”仍触发风险信号 | 风险评分、路由绕审核判断及降级策略复用同一否定规则；此例在无其他风险事实时风险分为 0 |
| 修正否定后可能误删真实风险或故障 | 保留“商品不能用”“不是没有质量问题”“不用审核，直接退款”等肯定/双重否定信号；金额和异常账号风险不受文本否定影响 |
| 选择器按原始词判为退款，而回答护栏按路由判为物流 | `RetrievalQuery` 显式携带 raw_query、primary_intent、action_type；政策工具沿链传递，选择器和回答护栏使用同一语义路由；物流咨询提及暂不退款时按物流政策检查 |

否定处理是有限范围的规则修复，不是完整自然语言理解或已核实商品事实。复杂转述、长距离否定仍需后续结构化事实提取与业务核验。旧调用缺少语义字段时保留原回退，离线 evaluator 口径未变。互补选择器仍受原实验配置控制。

## 正式持久化

`main.py` 的普通、SSE 请求默认进入 `persistent_api` → `DurableGraphRuntime` → 同一个 LangGraph；每个图节点同步保存 checkpoint。恢复提交 `None` 继续已保存状态，不重传原始用户输入。

- `run_id` 标识一轮执行，`conversation_id` 标识业务会话；持久化 owner 映射，恢复时重新鉴权。
- 创建、状态读取和执行共享线程锁、文件锁，同一磁盘路径的进程串行访问。
- 普通回复和 SSE 共用节点；需要证据审查的模型文本先缓冲，再输出审查结果。
- 会话两条消息与 `agent_persisted_turns` 标记在业务库同一事务中提交。若消息已提交、图 checkpoint 尚未完成，重试不重复保存；相同 turn_id 对应不同内容会报错。
- 完成任务再次恢复只读取既有结果。同一会话未完成任务阻止新一轮重叠执行。

路径、接口及回退方式见 [部署文档](../../docs/deployment.md)。依赖固定为 langgraph 1.2.10、checkpoint 4.2.0、sqlite saver 3.1.1、filelock 3.32.5，与本轮实际环境一致。没有修改本机真实服务配置或执行生产部署。

## 实际验证

| 检查 | 实际结果 |
|---|---|
| 隔离完整测试目录 | **329 passed、11 skipped、114 subtests passed**；10.53 秒；5 条框架弃用警告 |
| 本轮新增测试 | 10 项，覆盖语义否定、上下文传递、正式普通/SSE、任务鉴权、重复恢复、并行会话限制、消息提交后故障重试 |
| 两个独立进程的正式接口恢复 | 第一进程完成退款工具后 `os._exit(73)`，第二进程经正式 SSE 恢复，仅执行剩余 3 个节点 |
| 重启前后业务写入 | 退款记录 **1 → 1**，MQ 消息 **1 → 1**；会话消息 **0 → 2**，轮次提交标记 **0 → 1** |
| 已完成任务再次恢复 | 结果一致，无新增消息；其他用户查询和恢复均返回 404 |
| 会话写入后注入异常 | 首次 503；恢复 200，消息始终只有 2 条 |

完整测试目录为旧入口兼容性使用 `AGENT_RUNTIME=legacy`，新增正式接口测试显式启用 durable。进程恢复也启用 durable，使用正式 FastAPI 路由的 ASGI TestClient，不是网络部署测试。路由是声明的固定测试桩，工具、业务写入、图及 checkpoint 为实际代码；知识检索为本地模式，数据库为隔离 SQLite。

没有把以上结果视为意图识别准确率、RAG 提升率或生产成功率。11 项跳过不算通过。未在本轮验证真实 MySQL、Redis、支付渠道、跨机器并发或生产重部署。

## 边界与回退

目前是正式接口的单机持久化接入，恢复粒度为图节点；工具节点内部中断可能重试业务调用，因此不能宣称所有副作用恰好一次。会话去重已验证，外部支付仍依赖渠道幂等、查单与对账。Trace 写入不具备与 checkpoint 的跨存储事务保证。多个工作进程的文件锁实现已加入，本轮未做并发压力验证。

`AGENT_RUNTIME=legacy` 恢复原普通/SSE 入口；不删除 checkpoint 和业务轮次表。修改前源文件备份在 `before.zip`，不要整包覆盖本轮以外的新改动。

运行产物：[完整回归](tests_final.txt)、[进程恢复记录](process_recovery.json)、[退出进程日志](crash.log)、[恢复进程日志](resume.log)。可复现脚本：`scripts/dev/smoke_formal_recovery.py`，只使用临时隔离工作目录。
