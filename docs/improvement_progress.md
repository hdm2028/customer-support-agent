## P0 基线方法

`python -m scripts.eval.run_isolated_baseline --output reports/system_improvement/baseline_a`

每套评测在独立临时源码副本启动，使用新 SQLite、演示订单、进程内缓存、知识库副本和本地 256 维 embedding。语义路由调用当前配置的 LLM；现有工具、回答、端到端 evaluator 的 `use_llm=False` 只关闭最终回答生成，并不关闭语义路由。工具评测显式执行写操作，所有写入限制在副本。只复制四个明确指定的开发数据文件。原评分函数、分母和标签不变。

这是隔离开发配置的基线，不能代替 MySQL/Redis 并发验证或真实 LLM 最终回答质量测试。输出保留输入指纹、完整报告、逐请求 trace、原始运行日志和依赖诊断，不保存凭据。
